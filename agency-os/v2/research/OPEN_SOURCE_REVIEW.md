# Исследование открытых репозиториев
Дата проверки: 10 октября 2026. Изучены README через подключённый GitHub; это проверка заявленных функций и архитектуры, не аудит кода или доказательство роста Instagram.

| Источник | Что переносим в свою методику | Что не включаем в MVP |
|---|---|---|
| [Content Dashboard](https://github.com/tenfoldmarc/content-dashboard) | Свои посты → аномалии → семейства хуков → сценарий → очередь → замер | Скрейпинг как обязательный источник, автоматическое назначение admin пользователю без роли |
| [Marketing Dashboard](https://github.com/builderz-labs/marketing-dashboard) | Очередь согласования, статус задачи, CRM и KPI в одном цикле | Установка alpha-приложения и сложная инфраструктура |
| [GrowthBook](https://github.com/growthbook/growthbook) | Паспорт гипотезы, определение метрики, ограничения и документация эксперимента | Применение статистики рандомизированного A/B к обычным органическим постам |
| [Postiz](https://github.com/gitroomhq/postiz-app) | Отдельная очередь публикации и адаптер к издателю | Копирование AGPL-кода в собственный модуль; публикация без согласования |
| [Airbyte](https://github.com/airbytehq/airbyte) | Отделение источника данных от преобразования и назначения | Установка платформы ради нескольких CSV |
| [PostHog](https://github.com/PostHog/posthog) | События переходов и продаж вне Instagram, связь контента с воронкой | Обещание отслеживать скрытые действия внутри Instagram |
| [Ayrshare SDK](https://github.com/ayrshare/social-media-api) | Разделение аналитики поста, аккаунта и ссылок | Подписка на платный API и автоматические рассылки |

PostTrends: README описывает анализ привычек публикации; пригоден как исторический пример, недостаточен как современный источник Insights.
kevva/instagram-analytics: README.md не получен (404), подходы не заимствуем.
Мы реализуем собственные процессы, не копируем исходники. Лицензии отдельных компонентов проверяются перед будущей интеграцией. README blob SHA и ссылки сохранены в SOURCE_MANIFEST.json.
