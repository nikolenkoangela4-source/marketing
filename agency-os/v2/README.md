# Premium Instagram Agency: reviewable proposal
Дата: 10 октября 2026. Статус: дополнение подготовлено для review в отдельной ветке по подтверждению пользователя.
Целевой репозиторий: nikolenkoangela4-source/marketing, каталог agency-os/v2/.
В marketing уже есть Agency OS и Growth Cycle. Этот пакет дополняет их; существующие файлы не заменяются.
Начните с research/STORYTELLING_FUNNELS.md и docs/OPERATING_METHOD.md.

## Структура
- research/ — проверенные источники и наблюдаемые воронки.
- docs/ — конкуренты, метрики, цикл роста, качество данных.
- roles/ — ответственность продюсера и критика.
- templates/ — бриф, тест, редакционное ревью, отчёт.
- examples/ — только синтетические данные.
- tools/ — автономный расчёт показателей по CSV, без сетевых запросов.
- tests/ — проверки обработки пропусков и знаменателей.
- IMPLEMENTATION_PLAN.md — точный порядок внесения изменений после подтверждения.

## Запуск
Python 3.10+, стандартная библиотека:
`python tools/metrics.py examples/media.csv`
`python -m unittest discover -s tests`
Работает только локальный калькулятор. API, издатель, рассылки и независимые агенты не развёрнуты.
Клиентские данные хранить в закрытом проекте; публичный marketing получает методику и синтетические примеры.
