# Контракт метрик
API-поля провайдера подтверждать discovery на подключённом аккаунте. Этот документ задаёт внутренние определения; интеграция с API здесь не реализована.

| Показатель | Расчёт/смысл | Ограничение |
|---|---|---|
| Охват | reach из источника | Уникальные аккаунты в пределах определения источника; нельзя складывать охват постов и называть уникальным месячным охватом |
| Просмотры | views с определением источника | Не уникальные люди; не объединять plays, impressions и views без подтверждения эквивалентности |
| ER по охвату | 100×(likes+comments+saves+shares)/reach | Операционное определение агентства; при недоступном компоненте null |
| Отправки/распространение | 1000×shares/reach | shares не переименовывать в DM sends без подтверждения источника |
| Репосты | 1000×reposts/reach | Отдельное поле; не складывать с shares без определения пересечения |
| Комментарии | 1000×comments/reach | Ответы бренда и кодовые слова отдельно для качества |
| Сохранения | 1000×saves/reach | Показывают действие, не продажи |
| Просмотры на охваченного | views/reach | Не доказательство повторного просмотра каждого человека |
| Рост подписчиков | конец−начало | Net growth; при наличии gross follows/unfollows показывать отдельно |
| Конверсия этапа | уникальные перешедшие / уникальные на прошлом этапе | Одна когорта и окно, без смешения общего профиля с атрибуцией конкретному посту |

Ключ снимка: account_id, media_id, source, captured_at, window. Хранить source_fetched_at, published_at, timezone, api_version/definition_version, format, paid/collab/trial flags и исходный payload в закрытом проекте.
null = нет данных; 0 = измеренный ноль. Нулевой знаменатель → null. Не суммировать lifetime-снимки. Для baseline использовать одинаковый формат, возраст, тип распределения, рынок и сопоставимое предложение. Медиана, квартильный диапазон, n и доля пропусков обязательны. Если признаки paid/collab неизвестны — группа не считается чисто органической.
Текущий Growth Cycle в marketing имеет lifetime-baseline: использовать как контекст, а не matched-age доказательство. Новое сравнение по 48ч/7д требует настоящих исторических снимков, его нельзя восстановить подменой дат.
