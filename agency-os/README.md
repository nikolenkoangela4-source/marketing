# Agency OS — навигация

## Последовательность работы

1. Определить клиента, действующий бриф, доступ к данным и один результат теста.
2. Зафиксировать источник, дату, ограничения и исходные показатели.
3. Выбрать одну проверяемую гипотезу и главную метрику до производства.
4. Провести проверки Growth Critic и Text Critic; сохранить замечания.
5. Подготовить конкретный материал для проверки клиентом.
6. Связать опубликованную версию с media_id, временем и подтверждённым разрешением.
7. Сделать контрольные замеры и записать решение: REPEAT / ITERATE / RETEST / RETIRE / INCONCLUSIVE.

## Первый цикл

[Задача 2026-10-07](../tasks/2026-10-07-first-client-cycle.md). Клиентские данные и производственные материалы — в приватном `Secret-Marketing-RU`.

Роли выполняет доступный ассистент по явным этапам с сохранением артефактов. Независимость проверки нельзя выводить из названия роли: если автор и проверяющий — один ассистент, это внутреннее саморевью, а не независимое испытание.

## Публикация и наблюдение

Windsor.ai Instagram используется для чтения Insights. Публикация через этот коннектор недоступна. Тест считается опубликованным только после получения фактического media_id и времени публикации. Статус COMPLETE возможен после замера и записанного решения.

## Исполняемый инструмент

[Growth Cycle](tools/README.md): Python CLI для исходного контекста, ретроспективы, фиксации замера и проспективного решения. Входные выгрузки и результаты остаются в закрытом клиентском каталоге.
