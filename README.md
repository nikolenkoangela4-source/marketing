## Текущее состояние — 7 октября 2026

В `agency-os/` сохранены 13 методических документов: роли, редакционные проверки, анализ рынка и аудитории, рост, конверсия, дистрибуция, модель данных и подбор компонентов.

Методология реализуется поэтапно. Наличие инструкции не означает работающего агента или подключённого сервиса. Развёрнутого клиентского кабинета и автоматического издателя пока нет. Статистика читается через доступный клиентский коннектор; публикация и контроль возраста поста проверяются отдельно.

## Рабочий цикл

Исходные показатели → гипотеза и главная метрика → контент → редакционная проверка → публикация утверждённой версии → замеры по возрасту поста → решение.

Сравнивать следует одинаковые форматы и сопоставимый возраст публикаций. Поздние lifetime-значения не подменяют замеры за первые 48 часов. Единичный удачный пост даёт основание для повторного теста, а не доказательство причинности.
